Projet Final - Votre Projet Personnel

Objectif

Chaque étudiant crée son PROPRE projet UX/UI complet. Vous choisissez VOTRE sujet, VOTRE problématique, VOTRE solution.

Pas de projet imposé! C est VOTRE projet, VOTRE création, VOTRE portfolio.

Comment choisir votre projet?

Critères de validation

Votre projet doit: 1. Résoudre un problème réel à Madagascar 2. Avoir une cible claire (qui sont vos utilisateurs?) 3. Être réalisable en 2 jours (MVP) 4. Vous passionner (vous allez y passer 10h!)

Idées de domaines

  • 🌾 Agriculture (app pour agriculteurs, marché, coopératives)
  • 🏥 Santé (rendez-vous médicaux, pharmacies, urgence)
  • 📚 Éducation (e-learning, tutorat, bibliotheque)
  • 🚗 Transport (taxi-be, covoiturage, livraison)
  • 🛒 Commerce (e-commerce local, artisanat, services)
  • 🏠 Services (plomberie, électricité, réparation)
  • 💰 Finance (épargne, micro-crédit, budget)
  • 🎉 Événements (mariages, concerts, fêtes)

Exemples de projets possibles

Exemple 1: App “Médecin de Garde”

Problème: Difficile de trouver un médecin de garde la nuit à Tana Solution: App qui liste les médecins de garde par quartier Cible: Habitants d Antananarivo

Exemple 2: App “Taxi-Be Connect”

Problème: Attendre le taxi-be sans savoir quand il arrive Solution: App de suivi des lignes de taxi-be Cible: Usagers du taxi-be

Exemple 3: App “Marché Fresh”

Problème: Les ménagères veulent des légumes frais sans aller au marché Solution: Livraison de légumes frais des agriculteurs aux ménages Cible: Mères de famille, working moms

Exemple 4: App “Réparateurs Pro”

Problème: Difficile de trouver un bon plombier électricien fiable Solution: Marketplace de réparateurs vérifiés Cible: Propriétaires, locataires

Exemple 5: App “Devoirs Faciles”

Problème: Les parents ne peuvent pas aider leurs enfants pour les devoirs Solution: App de tutorat entre élèves Cible: Élèves, parents, étudiants tuteurs

Les livrables attendus

Obligatoires (minimum)

  1. Fiche projet (1 page)
    • Nom du projet
    • Problème résolu
    • Cible (utilisateurs)
    • Solution proposée
  2. 2 Personnas (30 min)
    • Persona principal
    • Persona secondaire
    • Avec photo/dessin, citations, frustrations
  3. User Journey Map (1 heure)
    • Parcours complet de votre utilisateur
    • 4 phases: Début → Recherche → Action → Fin
    • Émotions à chaque étape
  4. Wireframes papier (1 heure)
    • Minimum 3 écrans
    • Au crayon, pas besoin d être artiste
    • Focus sur la structure, pas la beauté
  5. UI Finale Figma (3 heures)
    • 3 écrans minimum en haute fidélité
    • Respectant votre Design System
    • Couleurs, typographie, espacements soignés
  6. Présentation (5 min)
    • Pitch du projet
    • Démo des écrans
    • Ce que vous avez appris

Bonus (pour les plus avancés)

  1. Design System mini
    • 3-4 couleurs
    • 1-2 polices
    • 2-3 composants
  2. Prototype cliquable
    • Liens entre écrans
    • Interactions de base
  3. Tests utilisateurs
    • Faire tester à 2-3 personnes
    • Noter les feedbacks

Planning des 2 jours

Jour 4 (après-midi) - Ideation

13h-14h: Brainstorm individuel - Noter 5 problèmes que vous rencontrez - Choisir LE problème qui vous passionne - Valider avec le formateur

14h-15h: Fiche projet - Définir le problème clairement - Identifier la cible - Esquisser la solution

15h-17h: Research - Interviewer 2-3 personnes (collègues, amis) - Valider que le problème existe vraiment - Ajuster si nécessaire

Jour 5 (matin) - Conception

8h-9h: Personas - Créer 2 personas détaillés

9h-10h30: User Journey - Mapper le parcours complet

10h30-12h: Wireframes papier - 3 écrans minimum - Itérer rapidement

Jour 5 (après-midi) - Finalisation

13h-15h: UI Figma - Transposer en haute fidélité - Appliquer Design System

15h-16h: Polish - Alignement, espacements, états - Demander feedbacks

16h-17h: Présentations - 5 min par étudiant - Vote pour les meilleurs projets

Conseils pour réussir

Choix du projet

  • ✅ Choisissez un problème que VOUS connaissez
  • ✅ Un problème que vous avez VOTRE avis
  • ✅ Quelque chose qui vous PASSIONNE
  • ❌ Évitez les sujets trop ambitieux
  • ❌ Évitez les sujets que vous ne comprenez pas

Gestion du temps

  • Ne passez pas 3h sur le choix du projet
  • Itérez rapidement (mieux vaut 3 versions moyennes qu 1 parfaite)
  • Demandez des feedbacks TÔT

Présentation

  • Répétez au moins 2 fois
  • Racontez une HISTOIRE (pas une liste de fonctionnalités)
  • Montrez votre PASSION
  • Soyez HONNÊTE sur les difficultés

Validation du projet

📝 Quiz: Quiz : Projet Final - Êtes-vous prêt?

1. Quels sont les 3 critères OBLIGATOIRES pour valider votre projet?

⬜ Beau, grand, coloré ✅ Résout un problème réel, cible claire, vous passionne ⬜ Utilise Figma, a 10 écrans, beaucoup d’animations ⬜ Gratuit, disponible en 1 jour, pour tout le monde

Les 3 critères sont : 1) Résout un problème réel à Madagascar, 2) A une cible claire (utilisateurs définis), 3) Vous passionne (vous allez y passer 10h!).

2. Combien de temps avez-vous pour réaliser votre projet final?

⬜ 1 semaine ✅ 2 jours ⬜ 1 mois ⬜ 5 heures

Le projet final se réalise sur 2 jours : Jour 4 après-midi (idéation) + Jour 5 (conception et finalisation).

3. Quels sont les livrables OBLIGATOIRES minimum?

⬜ Logo + Slogan + Vidéo ✅ Fiche projet + 2 Personas + User Journey + Wireframes + UI Figma + Présentation ⬜ Code source + Base de données + Serveur ⬜ Dessin sur papier + Maquette Photoshop

Les 6 livrables obligatoires sont : 1) Fiche projet, 2) 2 Personas, 3) User Journey Map, 4) Wireframes papier (3 min), 5) UI Figma (3 écrans min), 6) Présentation (5 min).

4. Pourquoi est-il important de choisir un problème que VOUS connaissez?

⬜ Pour finir plus vite ✅ Pour avoir un avis personnel et de l’empathie pour les utilisateurs ⬜ Pour ne pas avoir à faire de research ⬜ C’est obligatoire par le formateur

Choisir un problème que vous connaissez personnellement vous donne : de l’empathie naturelle, des insights réels, et de la passion pour le projet.

5. Quelle est la durée de la présentation finale?

⬜ 2 minutes ✅ 5 minutes ⬜ 10 minutes ⬜ 15 minutes

Chaque étudiant a 5 minutes pour présenter : pitch du projet + démo des écrans + ce que vous avez appris.

6. Sur combien de points est évalué le projet final?

⬜ 50 points ⬜ 80 points ✅ 100 points ⬜ 120 points

Le projet est noté sur 100 points répartis en 8 critères : Originalité (10), Personas (10), User Journey (10), Wireframes (10), UI finale (20), Présentation (10), IA (10), Accessibilité (10).

7. Quelle est la meilleure approche pour gérer votre temps?

⬜ Passer 5h sur le choix du projet pour être sûr ⬜ Faire une version parfaite du premier coup ✅ Itérer rapidement (mieux vaut 3 versions moyennes qu’1 parfaite) ⬜ Tout faire le dernier jour

L’itération rapide est clé : mieux vaut avoir 3 versions moyennes qu’une seule version parfaite. Demandez des feedbacks TÔT et ajustez.

8. Que devez-vous faire AVANT de commencer votre projet?

⬜ Acheter Figma Pro ✅ Faire valider votre idée par le formateur ⬜ Créer un compte GitHub ⬜ Imprimer les personas

Avant de commencer, vous devez faire valider votre idée par le formateur qui vous aidera à affiner l’idée, réduire le scope si nécessaire, et planifier les 2 jours.
