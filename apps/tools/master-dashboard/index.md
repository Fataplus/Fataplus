## 🚀 Utilisation

### Lancement du Dashboard
Le dashboard peut être ouvert en lançant `index.html` dans un navigateur web.

### Collecte de Données
Le script `scan_system.py` est utilisé pour:
- Scanner les répertoires de projet
- Collecter des métriques (git, fichiers, etc.)
- Générer le `data.json`
