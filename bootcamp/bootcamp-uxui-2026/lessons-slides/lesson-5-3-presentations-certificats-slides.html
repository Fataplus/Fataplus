Guide de Présentation

Structure de ta présentation (5 min)

1. Introduction (30 secondes)

"Bonjour, je m'appelle [Ton Prénom].
Aujourd'hui, je vais vous présenter mon projet :
Kianda, une application pour les agriculteurs malgaches."

2. Le Problème (1 minute)

"Laissez-moi vous présenter Ravo, notre utilisateur principal.

Ravo est agriculteur à Antsirabe. Il a 45 ans.
Ses problèmes :
- Il ne sait pas quand planter
- Il a du mal à trouver des acheteurs
- Il perd du temps à gérer ses cultures

C'est pour Ravo que j'ai conçu Kianda."

3. La Solution (2 minutes)

"Voici Kianda, l'application qui aide les agriculteurs.

[Montre le prototype]

Sur l'écran d'accueil, Ravo voit :
- La météo du jour
- L'état de ses cultures
- Ses actions prioritaires

Dans 'Mes Cultures', il peut :
- Suivre chaque parcelle
- Voir l'état de santé
- Planifier les prochaines actions

Dans 'Marché', il peut :
- Voir les prix actuels
- Trouver des acheteurs
- Vendre ses produits

J'ai choisi le vert comme couleur principale parce que
ça représente l'agriculture et la nature."

4. Les Choix de Design (1 minute)

"Pour ce projet, j'ai fait plusieurs choix :

COLORIS :
- Vert primaire pour l'agriculture
- Orange pour les actions importantes
- Beaucoup de blanc pour la lisibilité

TYPOGRAPHIE :
- Poppins pour les titres (moderne, lisible)
- Inter pour le corps (excellent à l'écran)

NAVIGATION :
- 4 onglets simples
- Icônes claires
- Labels explicites

Le tout pensé pour Ravo, qui n'est pas habitué aux apps."

5. Conclusion (30 secondes)

"En conclusion, Kianda est une application qui :
- Aide les agriculteurs comme Ravo
- Est simple à utiliser
- Résout des problèmes réels

Ce que j'ai appris :
- L'importance du persona
- La méthode Atomic Design
- Comment utiliser Figma

Merci pour votre attention !
Avez-vous des questions ?"

Conseils pour une bonne présentation

Avant la présentation

Préparation technique - [ ] Vérifier que le prototype fonctionne - [ ] Avoir une connexion internet stable - [ ] Fermer les notifications - [ ] Préparer un plan B (screenshots si le prototype bug)

Préparation mentale - [ ] Répéter au moins 3 fois - [ ] Chronométrer (pas plus de 5 min) - [ ] Préparer les réponses aux questions probables - [ ] Respirer et se détendre

Pendant la présentation

Le langage corporel - 👀 Regarder le public (pas l’écran) - 🧍 Se tenir droit - 🙌 Utiliser les mains naturellement - 😊 Sourire

La voix - 🗣️ Parler assez fort - 🐌 Parler lentement - ⏸️ Faire des pauses - 📈 Varier l’intonation

Les mots - ✅ “Voici…” “Comme vous pouvez voir…” - ❌ “Euh…” “En fait…” “Donc…” (trop répété)

Gérer les questions

Types de questions probables :

1. “Pourquoi cette couleur ?”

"J'ai choisi le vert car c'est la couleur de l'agriculture.
C'est aussi une couleur apaisante qui inspire confiance."

2. “Comment as-tu pensé à Ravo ?”

"J'ai créé un persona basé sur des agriculteurs réels.
À chaque décision, je me demandais :
'Est-ce que Ravo comprendrait ça ?'"

3. “Qu’est-ce que tu changerais ?”

"Si j'avais plus de temps, j'ajouterais :
- Des notifications push
- Une fonction de chat avec les acheteurs
- Un système de paiement intégré"

4. “Quel a été le plus grand défi ?”

"Le plus grand défi a été de garder l'interface simple
pour Ravo tout en offrant assez de fonctionnalités."

Les prochaines étapes

Pour continuer ton apprentissage

1. Pratiquer régulièrement - Reproduire des apps que tu aimes - Créer des projets personnels - Participer à des challenges UI

2. Approfondir Figma - Auto Layout avancé - Components variants - Plugins utiles - Collaboration en équipe

3. Apprendre les bases du code - HTML/CSS basics - Comprendre comment ton design est implémenté - Communiquer avec les développeurs

4. Construire un portfolio - 3-5 projets de qualité - Case studies complètes - Présenter ton processus

5. Rejoindre la communauté - Discord design francophone - LinkedIn : designers UI/UX - Dribbble, Behance pour l’inspiration
