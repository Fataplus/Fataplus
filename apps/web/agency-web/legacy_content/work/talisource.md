## Overview

Talisource addresses the complexity of modern recruitment by offering a seamless digital experience. The platform was designed to be robust yet accessible, serving both recruiters and candidates with equal care.

## Design System

We established a comprehensive design system ensuring consistency across all touchpoints. The interface uses Poppins typography for readability and a grid system that adapts perfectly to all devices.

## Impact

With features like automated screening and smart notifications, Talisource empowers HR teams to focus on what matters most: the people.
