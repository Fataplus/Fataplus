## Notes supplémentaires pour le présentateur

### Timing suggéré
- **Total : 7-8 minutes**
- Introduction : 30 secondes
- Problème : 1 minute
- Histoire personnelle : 1 minute 30
- Solution : 1 minute
- Pourquoi maintenant : 1 minute
- Marché : 1 minute
- Modèle économique : 45 secondes
- Produits : 45 secondes
- Différenciation : 30 secondes
- Équipe : 30 secondes
- Roadmap : 30 secondes
- Demande : 30 secondes
- Conclusion : 30 secondes

### Conseils de présentation

1. **Rythme** : Ne pas lire les slides. Le pitch deck est un support visuel, pas un script. Le vrai contenu est ce que vous dites.

2. **Contact visuel** : Parlez à l'audience, pas au slide. Regardez les gens dans les yeux.

3. **Gestuel** : Utilisez vos mains pour accentuer les points clés. Mouvement quand on parle de croissance/échelle. Statique quand on parle de validation/concrétisation.

4. **Variation de ton** :
   - **Problème** : Sérieux, grave
   - **Solution** : Enthousiaste, énergique
   - **Marché/Chiffres** : Précis, analytique
   - **Équipe** : Fierte, sincérité
   - **Conclusion** : Émotionnel, inspirant

5. **Pause stratégique** : Après chaque section majeure, faites une pause de 2-3 secondes. Laissez l'information être assimilée.

6. **Questions anticipées** : Soyez prêt à répondre à :
   - "Comment vous validez que les idées valent la peine d'être accompagnées ?"
   - "Comment vous gérez l'equity dans les startups ?"
   - "Comment vous différenciez d'un incubateur ou d'une agence ?"
   - "Quels sont vos KPIs ?"
   - "Comment vous trouvez vos clients ?"
   - "Quelle est la relation avec Zafy Tody ?"

### Ajustements selon l'audience

**Pour investisseurs VC** :
- Accent sur le modèle économique et le scalability
- Mettre en avant les equity stakes dans les startups incubées
- Parler d'exit strategy
- Plus de focus sur les chiffres de marché

**Pour partenaires incubateurs** :
- Accent sur la méthodologie et l'expertise
- Mettre en avant la complémentarité
- Parler de co-branding et de partage de ressources
- Plus de focus sur la transmission de compétences

**Pour clients entreprises** :
- Accent sur les résultats tangibles
- Mettre en avant les délais et la garantie
- Parler de ROI du consulting
- Plus de focus sur les case studies (même si pilote)
