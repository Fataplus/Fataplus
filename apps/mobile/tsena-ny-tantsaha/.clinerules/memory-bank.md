# Memory Bank Rule

**MANDATORY:**  
At the start of every session and before any significant project action, you MUST read, understand, and update (if needed) every file inside the `memory-bank/` directory, in the following order:

1. `projectbrief.md` – Project requirements, goals, and scope
2. `productContext.md` – Product purpose, problems solved, user experience
3. `systemPatterns.md` – Architecture, design patterns, technical decisions
4. `techContext.md` – Technology stack, setup, constraints, dependencies
5. `activeContext.md` – Current work focus, recent changes, next steps
6. `progress.md` – What works, what’s left, current status, known issues

**This process is required for all contributors and for Cline’s operation.  
No work may proceed without first consulting and, if necessary, updating these files.**

If any file is missing, it must be created and completed before continuing.
