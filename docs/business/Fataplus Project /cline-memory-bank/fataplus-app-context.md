# Contexte — fataplus-app

## Présentation

fataplus-app est une application Next.js, basée sur le boilerplate de whop.com.  
Elle sert de front-end moderne, réutilisant les bonnes pratiques et l’architecture du template whop.com.

## Stack technique

- **Framework principal :** Next.js (React)
- **Langage :** TypeScript
- **Organisation :** 
  - app/ (routes, composants, logique principale)
  - pages/ (routes traditionnelles Next.js)
  - lib/ (fonctions utilitaires, accès API, etc.)
  - styles/ (CSS global, modules)
  - public/ (assets statiques)
  - tests/ (tests unitaires et d’intégration)
  - types/ (définitions TypeScript)

## Objectif

- Fournir une interface utilisateur moderne et performante, inspirée du modèle whop.com.
- Servir de base pour des développements front-end rapides et évolutifs.

## Historique / Notes

- Structure héritée du boilerplate whop.com, adaptée aux besoins Fataplus.
- Séparation claire des responsabilités (pages, composants, logique métier).
- Prêt pour l’intégration avec des APIs ou des backends externes.
