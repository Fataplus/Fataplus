Introduction à Figma - Ton Nouvel Atelier

Qu’est-ce que Figma?

Figma est un logiciel de design d’interface, gratuit et dans le navigateur. C’est comme avoir un atelier de design complet, accessible depuis n’importe quel ordinateur.

Analogie Madagascar 🇲🇬

Figma, c’est comme ton echoppe au marché : - Tu as ton espace de travail - Tes outils sont toujours là - Tu peux montrer ton travail aux clients - Tu peux collaborer avec d’autres vendeurs

Mais en version numérique et gratuite !

Pourquoi Figma?

✅ Gratuit - Pas besoin de payer ✅ Dans le navigateur - Aucune installation ✅ Collaboration en temps réel - Travailler à plusieurs ✅ Standard de l’industrie - Utilisé par les pros ✅ Multi-plateforme - Windows, Mac, Linux, Chromebook

Les alternatives (pour info)

  • Sketch - Mac seulement, payant
  • Adobe XD - Payant
  • Canva - Trop simple pour le design UI pro

Figma = Le meilleur choix pour débuter et continuer.

Créer ton compte Figma (10 min)

Étape 1 : Aller sur figma.com

  1. Ouvre ton navigateur
  2. Tape figma.com dans la barre d’adresse
  3. Clique sur “Sign up” (S’inscrire)

Étape 2 : Créer le compte

Choisis une méthode : - Email - Entre ton email et crée un mot de passe - Google - Connexion rapide avec Gmail

Étape 3 : Configurer ton profil

  • Name : Ton prénom + nom (professionnel)
  • Role : Designer ou Student
  • Use case : Design pour des apps/sites web

Étape 4 : Choisir le plan gratuit

Figma propose un plan payant, mais le plan gratuit suffit pour ce bootcamp et au-delà.

⚠️ Ne pas payer - Le plan Starter (gratuit) est parfait !

1. Zone de gauche (Layers/Calques) - Liste de tous les éléments - Comme les couches d’un gâteau - Le haut = premier plan, le bas = arrière-plan

2. Zone centrale (Canvas/Toile) - Ton espace de dessin - Infini ! Tu peux zoomer et dézoomer

3. Zone de droite (Design/Properties) - Propriétés de l’élément sélectionné - Couleur, taille, position, etc.

4. Barre d’outils (Top) - Outils de dessin - Frame, Rectangle, Texte, Main, etc.

Les outils essentiels (30 min)

1. L’outil Frame (F) - La Fondation

Frame = Conteneur = La base de tout design

Analogie : Une frame, c’est comme un cadre photo ou une page de cahier.

Comment créer une Frame :

  1. Appuie sur F ou clique sur l’icône Frame
  2. Dessine un rectangle sur la toile
  3. Ou choisis une taille prédéfinie (iPhone, Desktop, etc.)

Tailles courantes :

  • Mobile : 375 × 812 px (iPhone X)
  • Tablet : 768 × 1024 px (iPad)
  • Desktop : 1440 × 900 px (Laptop)
  • Story Instagram : 1080 × 1920 px

Exercice : Créer une Frame Mobile

  1. Appuie sur F
  2. Dans le panneau droit, cherche “Phone”
  3. Choisis “iPhone 14 & 15 Pro Max” (430 × 932)
  4. Nomme ta frame “Accueil App”

2. L’outil Rectangle (R) - Les Formes

Rectangle = Bloc carré ou rectangle

Analogie : Comme découper du papier coloré.

Comment créer un Rectangle :

  1. Appuie sur R
  2. Dessine sur la toile
  3. Modifie la couleur dans le panneau droit

Propriétés importantes :

  • W (Width) = Largeur
  • H (Height) = Hauteur
  • Fill = Couleur de remplissage
  • Stroke = Bordure
  • Corner radius = Coins arrondis

Exercice : Créer un bouton

  1. Crée un rectangle de 200 × 50 px
  2. Donne-lui une couleur (ex: bleu #3B82F6)
  3. Arrondis les coins à 25px
  4. Nomme-le “Button Primary”

3. L’outil Texte (T) - Les Mots

Texte = Écrire des mots

Analogie : Comme écrire au stylo, mais modifiable.

Comment créer du Texte :

  1. Appuie sur T
  2. Clique sur la toile
  3. Tape ton texte

Propriétés importantes :

  • Font = Police (Inter, Roboto, etc.)
  • Size = Taille (16px, 24px, etc.)
  • Weight = Épaisseur (Regular, Bold)
  • Line height = Espacement entre lignes
  • Letter spacing = Espacement entre lettres

Exercice : Ajouter du texte au bouton

  1. Crée un texte “Connexion”
  2. Police : Inter, Bold, 16px
  3. Couleur : Blanc #FFFFFF
  4. Centre-le dans ton bouton

4. L’outil Main (H) - Navigation

Main = Se déplacer dans le canvas

Raccourcis de navigation :

  • H + glisser = Déplacer la vue
  • Molette + glisser = Déplacer la vue
  • Scroll = Zoom vertical
  • Shift + Scroll = Zoom horizontal
  • Ctrl/Cmd + + = Zoom avant
  • Ctrl/Cmd + - = Zoom arrière
  • Ctrl/Cmd + 0 = Zoom 100%
  • Ctrl/Cmd + 1 = Voir tout le fichier

5. L’outil Sélection (V) - Choisir

Sélection = Cliquer sur un élément pour le modifier

Raccourcis de sélection :

  • V = Outil sélection
  • Clic = Sélectionner
  • Double-clic = Entrer dans un groupe
  • Shift + clic = Sélection multiple
  • Ctrl/Cmd + A = Tout sélectionner
  • Échap = Désélectionner

Exercice pratique : Créer un bouton complet (30 min)

Objectif

Créer un bouton “Acheter maintenant” professionnel.

Étapes :

1. Créer la frame - Frame : 375 × 812 px (iPhone) - Fond : #FFFFFF (blanc)

2. Créer le bouton - Rectangle : 300 × 50 px - Couleur : #10B981 (vert) - Coins arrondis : 25px - Centrer horizontalement

3. Ajouter le texte - Texte : “Acheter maintenant” - Police : Inter, Bold, 16px - Couleur : #FFFFFF (blanc) - Centrer dans le bouton

4. Grouper - Sélectionne le rectangle + texte - Ctrl/Cmd + G = Grouper - Nomme le groupe “Button-Buy”

La hiérarchie des calques (10 min)

Comprendre les calques

Les calques (layers) sont comme des feuilles transparentes empilées :

┌─────────────────────────┐
│  Couche 1 : Texte       │  ← Premier plan (visible)
├─────────────────────────┤
│  Couche 2 : Bouton      │
├─────────────────────────┤
│  Couche 3 : Fond        │
├─────────────────────────┤
│  Couche 4 : Frame       │  ← Arrière-plan
└─────────────────────────┘

Manipuler les calques :

  • Glisser vers le haut = Mettre en avant
  • Glisser vers le bas = Mettre en arrière
  • Œil = Masquer/Afficher
  • Cadenas = Verrouiller/Déverrouiller

Les couleurs dans Figma (15 min)

Le sélecteur de couleurs

Clique sur la couleur Fill pour ouvrir le sélecteur :

1. Formats de couleur - HEX : #3B82F6 (6 caractères) - RGB : rgb(59, 130, 246) - HSL : hsl(217, 91%, 60%)

2. Opacité - 100% = Totalement opaque - 50% = Semi-transparent - 0% = Invisible

Analogie Madagascar 🇲🇬

Les couleurs HEX, c’est comme les codes MVola : - Chaque code est unique - Tu dois le taper exactement - Un mauvais chiffre = mauvaise couleur

Exercice : Créer une palette

    • Secondaire : #10B981 (vert)
    • Accent : #F59E0B (orange)
    • Neutre : #6B7280 (gris)

Les composants - Intro (15 min)

Qu’est-ce qu’un composant?

Un composant est un élément réutilisable.

Analogie Madagascar 🇲🇬 : Un composant, c’est comme un moule à mofo gasy : - Tu crées le moule une fois - Tu peux en faire 100 mofo identiques - Si tu modifies le moule, tous les mofo changent

Créer un composant :

  1. Dessine un bouton complet
  2. Sélectionne-le
  3. Clique sur le ◇ (losange) dans la barre d’outils
  4. Ou : Ctrl/Cmd + Alt + K

Utiliser un composant :

  1. Va dans la section “Assets” (calques)
  2. Glisse ton composant sur la toile
  3. C’est une instance = une copie liée

Modifier le composant :

  • Modifier le maître = change toutes les instances
  • Modifier une instance = ne change que celle-ci (sauf structure)

Sauvegarder et exporter (5 min)

Sauvegarde automatique

Figma sauvegarde automatiquement ! Pas besoin de Ctrl+S.

Mais tu peux : - File → Save as = Nouvelle version - File → Version history = Voir les versions

Exporter ton design

  1. Sélectionne ta Frame
  2. Dans le panneau droit, section “Export”
  3. Clique sur +
  4. Choisis le format :
    • PNG : Pour le web, fond transparent possible
    • JPG : Photos, fond toujours blanc
    • SVG : Vecteurs, modifiable
    • PDF : Pour l’impression
  5. Choisis l’échelle (1x, 2x, 3x pour retina)
  6. Clique sur Export

📝 Quiz: Quiz : Introduction à Figma

1. Quel raccourci crée une Frame ?

⬜ R ⬜ T ✅ F ⬜ V

F = Frame. R = Rectangle, T = Texte, V = Sélection.

2. Quelle est la taille standard d’un iPhone moderne en design ?

⬜ 320 × 480 px ⬜ 375 × 667 px ✅ 430 × 932 px ⬜ 768 × 1024 px

430 × 932 px correspond à l’iPhone 14 Pro Max. Les anciens modèles sont plus petits.

3. Comment s’appelle une copie réutilisable d’un élément ?

⬜ Un clone ⬜ Un composant ✅ Une instance ⬜ Un duplicata

Un composant crée des instances. L’instance est liée au composant maître.

4. Quel format est le meilleur pour exporter avec fond transparent ?

⬜ JPG ✅ PNG ⬜ PDF ⬜ SVG

PNG supporte la transparence. JPG a toujours un fond (généralement blanc).

5. Comment dupliquer un élément rapidement ?

⬜ Ctrl+C puis Ctrl+V ✅ Alt + glisser ⬜ Clic droit → Duplicate ⬜ Ctrl+D

Alt + glisser est la méthode la plus rapide pour dupliquer dans Figma.
